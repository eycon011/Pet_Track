# 🐾 PetTrack

## Sobre o projeto

O **PetTrack** é um projeto desenvolvido para a faculdade com o objetivo de criar uma solução tecnológica voltada à **segurança, localização e monitoramento de animais de estimação**.

A proposta consiste em um sistema integrado que utiliza uma coleira inteligente, associada a recursos como **QR Code, GPS e monitoramento**, permitindo que o tutor tenha mais informações e controle sobre seu animal.

Além da proposta tecnológica, o PetTrack foi desenvolvido considerando uma arquitetura de software escalável, com potencial para evoluir para um modelo **SaaS (Software as a Service)**.

---

## 🚀 Tecnologias utilizadas

O projeto utiliza tecnologias modernas para a construção de sua estrutura:

### Backend

* Python
* FastAPI

### Frontend

* React

### Banco de Dados

* MySQL

---

## 💡 Principais funcionalidades

* 📍 Localização e rastreamento do pet por GPS;
* 🔳 Identificação do animal através de QR Code;
* 🐶 Cadastro e gerenciamento de informações dos pets;
* 👤 Cadastro e gerenciamento dos tutores;
* 📊 Centralização das informações em uma plataforma digital;
* ☁️ Estrutura pensada para evolução em um modelo SaaS;
* 🔐 Possibilidade de expansão para recursos de segurança e monitoramento.

---

## 🧠 Inteligência Artificial no desenvolvimento

Durante o desenvolvimento do PetTrack, ferramentas de **Inteligência Artificial foram utilizadas como copiloto**.

> **A IA foi copiloto, não piloto. O piloto sou eu.**

A Inteligência Artificial foi utilizada como ferramenta de apoio para:

* Auxílio na resolução de problemas;
* Consulta e compreensão de conceitos;
* Sugestões técnicas;
* Apoio durante o desenvolvimento;
* Otimização do processo de aprendizagem;
* Revisão e análise de possíveis soluções.

As decisões, implementações, validações e direcionamento do projeto foram realizados pelo desenvolvedor.

O objetivo da utilização da IA não foi substituir o desenvolvimento humano, mas **potencializar o processo de aprendizado e auxiliar na construção da solução**.

---

## 🎯 Objetivo

O PetTrack busca demonstrar como a tecnologia pode ser aplicada para resolver problemas reais relacionados à segurança e ao cuidado de animais de estimação.

O projeto também representa a aplicação prática dos conhecimentos adquiridos durante a graduação em **Análise e Desenvolvimento de Sistemas**, envolvendo conceitos de:

* Desenvolvimento Backend;
* Desenvolvimento Frontend;
* APIs;
* Banco de Dados;
* Arquitetura de Software;
* Modelagem de sistemas;
* Desenvolvimento de soluções SaaS;
* Utilização responsável de Inteligência Artificial como ferramenta de apoio.
